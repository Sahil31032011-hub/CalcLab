# CalcLab — All-in-One Calculator

A responsive, single-page calculator app with:

- Basic and scientific calculations
- Programmer/base conversion and bitwise operations
- Percentage and everyday money tools
- Finance, unit conversion, and date calculations
- Maths, geometry, statistics, and BMI tools
- Theme, background, and animation settings saved on the device

## Live app

https://all-in-one-t08h.hatchable.site

## Source

The app is currently implemented as a standalone HTML file in `public/index.html`. It uses browser-side HTML, CSS, and JavaScript; no build step is required.

## Run locally

Open `public/index.html` in a modern browser.
